# ⚡ NEON SURVIVOR

A hyper-satisfying neon roguelike survivor, built for one thumb and ten minutes
of pure flow. No assets, no frameworks, no excuses — every pixel, particle and
note is generated by code.

**Survive 10 minutes. Kill Omega Prime. Become the storm.**

## How to play

- **Drag anywhere** — steer your ship (floating joystick)
- **Tap** — dash (i-frames, damages everything you phase through)
- Desktop: **WASD/arrows** to move, **Space/Shift** to dash, **Esc** to pause
- Weapons aim and fire on their own. Your job is to *dance*.

### The core loop

- Kill → collect XP gems → **level up** → pick 1 of 3 upgrades
- **Graze** enemies and bullets (get close without getting hit) to charge
  **OVERDRIVE** — a 7-second gold frenzy: faster, stronger, huge magnet
- Chain kills to build a **combo** that multiplies XP and score
- Dash kills refund your dash — aggression is a resource
- Elites drop **supply chests**. Bosses hit at 3:00, 6:30 and 10:00
- Max a weapon + own its paired passive → **evolve** it into something absurd

### Meta

Runs earn **◆ shards** — spend them in the **Armory** (9 permanent upgrades)
and on 3 unlockable **Pilots** with distinct playstyles. Beat Omega Prime to
unlock **Endless Mode**.

## Tech

- TypeScript + Vite, zero runtime dependencies (~28 kB gzipped)
- Canvas 2D with pre-baked glow sprites & additive blending, object pooling,
  spatial hashing — steady 60 fps with 300+ enemies on mobile
- 100% procedural audio: WebAudio-synthesized SFX + layered synthwave loop
- Installable PWA, works fully offline
- Haptics, screen shake, hit-stop — all toggleable

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
```

Debug knobs: `?t=300` (start at 5:00) · `?god` (invincible) · `?speed=2` (fast-forward).
