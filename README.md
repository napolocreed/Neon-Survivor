# ⚡ NEON SURVIVOR

A hyper-satisfying neon roguelike survivor, built for one thumb and ten minutes
of pure flow. No assets, no engine, no dependencies — every pixel, particle and
note is generated by code at runtime.

**Survive ten minutes. Cross three sectors. Kill what waits at the end.**

## How to play

- **Drag anywhere** — steer. Guns aim and fire on their own.
- **Tap** — dash **toward the point you tapped**. Invulnerable mid-dash, and it
  damages everything you phase through. Taps within ~26° of an enemy snap onto it.
- **Ability button** — every pilot has a different active power.
- Desktop: **WASD/arrows**, **Space/Shift** dash, **E** ability, **Esc** pause.

### The mechanic that matters

**Kills fuel dashes.** Kill something with a dash and the next dash is *free* —
keep killing and it stays free. A dash that kills **nothing** spends a real
charge, so hammering the screen runs dry in two taps while aimed play flows
forever. Every link heals you, scales dash damage and floods Overdrive; the
window tightens past ×10 and i-frames thin as the chain deepens. Aggression is
the optimal strategy — *precise* aggression.

Around it:

- **Graze** — skim enemies and bullets without being hit to charge **OVERDRIVE**:
  seven gold seconds of speed, damage and magnetism.
- **Elemental reactions** — two different statuses on one enemy trigger chemistry:
  Burn + Chill detonates · Chill + Shock spreads the freeze · Shock + Acid arcs
  corrosion · Burn + Acid ignites the pool.
- **Defiance beacons** — optional. Touch one for 25 seconds of hell and a
  guaranteed reward. The tension is yours to choose.
- **Cursed Tech** — beaten bosses offer real power for a real price.
- **Grid Protocols** — every run rolls a mutator that changes its texture
  (waves, decaying gems, a serpent that always re-forms, fog-of-war…).

### Arsenal — 16 weapons, 16 evolutions

Pulse Blaster · Arc Tesla · Nova Pulse · Homing Swarm · Rail Lance ·
Orbital Blades · Cryo Array · Acid Launcher · Boomerang Glaive · Mine Layer ·
Drone Turret · Void Orb · Flak Cannon · Photon Sweep · Ion Disc · Hunter Sigil

Max a weapon *and* own its paired passive to unlock its legendary evolution.

### The horde

Spawn pressure ramps from 3 to 24 enemies a second, and the standing population
climbs past 200 — a governor keeps it there rather than letting it saturate.
Contact damage is deliberately modest: with that many bodies you are always
touching *something*, so the horde is pressure, and the things that actually
kill you are the ones you can see coming. Spawn weights are set against
expected lifetime, not spawn share, so the swarm on screen is the swarm that
was designed rather than whatever survived longest.

### Bestiary

14 hostile types built around decisions, not stats — bait the **Sapper**'s blast
into the horde, outflank the **Aegis**'s directional shield, kill the **Mender**
first, break rhythm against the **Blink Stalker**. Plus elites with five affixes,
multi-segment **Void Serpents**, and **5 bosses** drawn into three slots, so the
boss rotation changes every run.

### Meta

- **◆ Shards** feed the **Nanite Matrix**, a three-branch talent tree
- **7 pilots**, each with distinct stats and an active ability
- **32 achievements**, a **Codex** of everything you have met, and a full
  **career record** with per-weapon damage breakdowns
- **⬖ Daily Challenge** — a UTC-date seed drives the entire run, so everyone
  plays the same grid on the same day
- Beat the final boss to unlock **Endless**

## Tech

- TypeScript + Vite. **Zero runtime dependencies.** 58 kB gzipped, all of it.
- Canvas 2D: pre-baked glow sprites, object pooling and a spatial hash. Every
  glow goes into one additive pass rendered to a **half-resolution bloom
  buffer** — a soft radial blur loses nothing at half res, and it took the
  enemy pass from 33 ms to 8.6 ms. Viewport culling on top. Steady 60 fps with
  a screen-filling horde.
- The whole simulation costs **0.59 ms** at 460 enemies, so the frame budget
  belongs to the picture.
- 100 % procedural audio: synthesized SFX and a layered synthwave score whose
  filter, bass and fills follow the intensity of the run
- Installable PWA, fully offline

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint     # tsc --noEmit
```

### Debug & instrumentation knobs

| Query param | Effect |
|---|---|
| `?t=300` | start the run at 5:00 |
| `?god` | invulnerable |
| `?speed=3` | run N game updates per frame |
| `?sim` | skip rendering entirely (~40× faster — used by the balance bench) |

`window.__game` exposes the live `Game` instance for probes and automated
playtests.
