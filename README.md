# ⚡ NEON SURVIVOR

A hyper-satisfying neon roguelike survivor, built for one thumb and ten minutes
of pure flow. No assets, no frameworks, no excuses — every pixel, particle and
note is generated by code.

**Survive 10 minutes. Cross three sectors. Kill Omega Prime. Become the storm.**

## How to play

- **Drag anywhere** — steer your ship (floating joystick)
- **Tap** — dash (i-frames, damages everything you phase through)
- **Ability button** — each pilot has a unique active power
- Desktop: **WASD/arrows** move, **Space/Shift** dash, **E** ability, **Esc** pause
- Weapons aim and fire on their own. Your job is to *dance*.

### The core loop

- Kill → collect XP gems → **level up** → pick 1 of 3 upgrades (reroll & banish)
- **Graze** enemies and bullets to charge **OVERDRIVE** — 7 s of gold frenzy
- Chain kills into a **combo** that multiplies XP; dash kills refund your dash
- Elites drop **supply chests** · bosses lock you in an **arena** at 3:00 / 6:30 / 10:00
- Beating a boss offers **CURSED TECH** — huge power for a painful price
- Max a weapon + own its paired passive → **evolve** it
- The world itself changes: **The Grid → Acid Wastes → Meltdown Core**, each
  with its own hazards
- Watch for **Void Serpents** — armored, snake through the field, weak at the head

### Meta

- **◆ Shards** feed the **Nanite Matrix** — a 3-branch talent tree
  (Offense / Survival / Fortune) with capstones: start at weapon level 2,
  revive, extra reroll & banish
- **5 pilots** with distinct stats *and* active abilities (Overload, Bullet
  Time, Aegis, Phantom Strike, Anomaly)
- **18 achievements** that pay out shards
- Beat Omega Prime to unlock **Endless Mode**

## Tech

- TypeScript + Vite, zero runtime dependencies
- Canvas 2D with pre-baked glow sprites & additive blending, object pooling,
  spatial hashing — steady 60 fps with 300+ entities on mobile
- 100 % procedural audio: WebAudio-synthesized SFX + layered synthwave loop
- Installable PWA, works fully offline
- Haptics, screen shake, hit-stop — all toggleable

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
```

Debug knobs: `?t=300` (start at 5:00) · `?god` (invincible) · `?speed=2` (fast-forward).
